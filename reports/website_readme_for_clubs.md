# Role-Based Recruitment Decision Support Demo

This is an interactive portfolio demo, not a final club recommendation product.

The workflow demonstrates:

1. Squad-need hypothesis from public/player-level data
2. Role-based longlist filtering
3. Configurable shortlist scoring
4. Player QA flags for further validation
5. Exportable outputs for analyst/scout discussion

## Why this matters

Recruitment decisions involve uncertainty: tactical fit, budget, availability, adaptation risk, contract situation and the limits of public data. This demo shows how those assumptions can be made explicit rather than hidden inside a single black-box ranking.

## What it does not claim

It does not replace:

- internal club scouting
- medical assessment
- wage and contract information
- agent or player willingness context
- coach/technical director judgement
- full tactical video review

The output should be read as a structured first-screening and validation workflow.
