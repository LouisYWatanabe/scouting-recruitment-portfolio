## Hero title

Role-Based Scouting Analytics Portfolio

## Subtitle

A public-data recruitment decision-support demo for football clubs, covering squad-need hypotheses, role-based longlists, configurable shortlists and QA flags for scout/video validation.

## Short description

This project demonstrates how publicly available football data can be structured into an explainable recruitment workflow. The tool helps frame possible squad needs, filter candidate pools, rank players under configurable tactical and financial assumptions, and highlight risks that should be validated by scouts, video analysts, medical staff and decision-makers.

## Methodology note

The portfolio is intentionally framed as decision support rather than an automated signing recommendation. Role-level scoring, reliability adjustment and value intelligence are used to prioritise candidates, while limitations around public data, market value proxies, injury history and tactical-role ambiguity are explicitly stated.
